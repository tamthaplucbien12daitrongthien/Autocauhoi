## Lenh (client)
/autocalc                         bat/tat
/autocalc delay <tick>            do tre truoc khi gui (20 tick = 1 giay, mac dinh 10)
/autocalc add tieng viet=English  them tu moi vao tu dien (luu o .minecraft/config/autocalc-dict.txt)
